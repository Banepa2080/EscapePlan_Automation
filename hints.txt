// //Hint about "fixture": 
a fixture is a reusable piece of code that sets something up before a test runs and can clean it up afterward

import pytest
from playwright.sync_api import sync_playwright

Fi) 
@pytest.fixture(scope="session")
def  browser():
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=False)  # set headless=True if you don't want to see the browser window
        yield browser
        browser.close()
hints: here the fixture browser
- Starts the browser(chromium) once per session
- yield lets the test use the browser
- After tests are done, browser is close

Fii)
@pytest.fixture
def page(browser):
    page = browser.new_page()
    yield page
    page.close()
Hints : the fixture page
- Uses the browser fixture
- Creates a new browser page for each test
- yield page gives the test a fresh tab
- After test, it closes the tab
